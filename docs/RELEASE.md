# Сдача и проверка

## Что должно быть готово перед передачей экспертам

| Требование | Как проверить |
|---|---|
| Распознавание по фото с использованием CV | Реальное фото → модели → карточка конкретного товара. |
| Оценочный HTTP API | `POST /v1/eval/predict`, multipart `image`, JSON `{"slug":"…"}`. |
| Веб-интерфейс | Загрузка, рамки бутылок, выбор цели, карточка, эталон и ссылка на «Своё вино». |
| Архитектура | Фактическая схема и карта исходников в `ARCHITECTURE.md`; граница модели и приложения явная. |
| Запуск | Проверенные команды Docker и перечисленные внешние зависимости в README. |
| Воспроизводимость | Версии пакетов, контрольные суммы локальных активов и профиля модели. |
| Качество | Метрики с размером и происхождением выборки; ограничения в `docs/QUALITY.md`. |
| Передача | Публичный репозиторий и доступный экспертам сервис/пакет запуска после решения владельца. |

Эта редакция подготовлена локально. Создание удаленного репозитория, публикация,
внешний адрес и передача закрытых модельных активов — отдельные действия.
Клонирование одних исходников не дает веса, каталог или работающий распознаватель.

## Сценарий демонстрации, до 7 минут

1. Загрузить фронтальную фотографию: рамка → карточка → эталон → ссылка.
2. Загрузить сцену с несколькими бутылками и выбрать нужную.
3. Показать обработку неподдерживаемого файла и недоступного распознавателя.
4. Открыть архитектуру: какие модули за что отвечают, где модели и данные.
5. Показать измеренное качество и назвать оставшиеся ограничения.

Для финального этапа требуется дополнительная функция после распознавания.
Ссылка на карточку каталога уже есть; соответствие этой функции ожиданиям жюри
нужно подтвердить перед сдачей. Отдельный рекомендательный сервис не реализован.

## Эксплуатационные границы

Начальный запуск рассчитан на локальную демонстрацию. Публикация в интернет
потребует выбранного адреса, TLS и ограничения доступа/нагрузки. Сервис не должен
отдавать диагностические поля с локальными путями и не хранит загруженные фотографии
как коллекцию. Для распознавания нужна доступность нативного процесса на Mac.

Веса, каталог и эталонные изображения предоставляются отдельно. Перед публикацией
проверяется весь Git, а не только последний коммит, а также состав Docker-образа.
