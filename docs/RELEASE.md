# Как проверить сервис

Короткий маршрут для знакомства со сканером. Установка для этого не требуется.

## 1. Загрузить фотографию

Откройте [wines.aiweapps.com](https://wines.aiweapps.com), загрузите фотографию
лицевой этикетки. Сервис покажет найденные бутылки. Выберите нужную и откройте
карточку: название, характеристики, эталонное фото и ссылку на «Своё вино».

Для сцены с несколькими бутылками можно выбрать другую бутылку на том же снимке.
[Мобильное приложение](https://github.com/AiweApps/rshb-hack-flutter) использует тот же API.

## 2. Проверить свою подборку через API

Из корня этого репозитория:

```bash
bash evaluation/organizer/participant_remote_test.sh \
  --images-dir /path/to/queries \
  --manifest /path/to/queries.tsv \
  --output predictions-remote.jsonl
```

Скрипт получает гостевой токен и отправляет фотографии на публичный сервис.
`queries.tsv` содержит две колонки: `query_id` и `image_path`, разделённые табуляцией.
В выходном JSONL одна строка на фото: идентификатор, путь, контрольная сумма,
предсказанный `slug` и время ответа `latency_ms`. **Slug — идентификатор карточки
в каталоге**, например часть адреса после `/wines/`. Скрипт сохраняет предсказания;
для подсчёта точности их сопоставляют с правильными ответами.

Формат входа и пример — [README](../README.md#оценщик-организатора).
[Локальный запуск](DEPLOYMENT.md#проверка-локального-api) описан отдельно.
Поля HTTP-ответов и авторизация — [API](API.md).
