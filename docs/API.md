# API и пакеты активов

## Маршруты шлюза

| Маршрут | Результат |
|---|---|
| `GET /` | Веб-интерфейс |
| `GET /health/live` | `{"live":true}` — HTTP-процесс жив |
| `GET /health/ready` | `{"ready":true}` и 200 либо `false` и 503 |
| `GET /api/status` | Готовность модели, совпадение профиля, очередь, лимиты, число карточек |
| `POST /api/recognize` | `{"view":…}` — цели и карточки для интерфейса |
| `POST /v1/eval/predict` | `{"slug":"…"}` либо `{"slug":null}` |
| `GET /api/reference/{slug}.jpg` | Миниатюра эталона или 404 |

Оба POST — `multipart/form-data` с полем `image`: JPEG, PNG или WebP, до 20 МиБ и
24 Мп. Необязательное `target_roi` — JSON `[x1,y1,x2,y2]` в пикселях оригинала
**после применения EXIF-ориентации**; рамка должна иметь положительную площадь и
лежать внутри изображения. Лимит тела проверяется до разбора, нужен `Content-Length`.

## Публичный сервис

Базовый адрес `https://vines.aiweapps.com`. Регистрация не нужна.

| Клиент | Вход |
|---|---|
| Браузер | Страница сама вызывает `POST /auth/guest` и получает HttpOnly-cookie на 24 ч |
| Приложение, скрипт | `POST /auth/guest/token` → `access_token` в JSON, заголовок `Authorization: Bearer …` |

```json
{"access_token":"<token>","token_type":"Bearer","expires_in":86400,"guest_id":"<id>"}
```

`/` и `/static/*` открыты; `/api/*` принимает cookie или Bearer; `/v1/eval/predict`
и `/health/*` — только Bearer. Миниатюру из `reference` запрашивайте с тем же
заголовком, внешнюю `page_url` открывайте обычной ссылкой без него. Токен не
передаётся в URL. Выход: `POST /auth/logout` с Bearer → 204.

Каждый вызов выдачи создаёт новую гостевую сессию: храните токен и используйте его
до истечения. Выдача и распознавание ограничены по частоте с одного IP; запросы к
модели обрабатываются последовательно, параллельная нагрузка ускорения не даёт.

## Ответ интерфейса

`view.bottles[]` содержит `instance_id`, `geometry`, `label_bbox`, `select_roi`,
`selectable`, `primary`, `addressed`, `decision`, `best`, `alternatives`.
`best` и `alternatives` — карточки с `slug`, `title`, `producer`, `category`,
`region`, `grapes`, `page_url`, `reference`. Повторный запрос по бутылке делается
с её `select_roi`, если `selectable`; рамка показа не всегда пригодна для запроса.

`primary_instance_id` связывает главную цель с карточкой. При явной рамке оценочный
ответ берётся у addressed-цели. Равноправные цели не разрешаются выбором первой,
порядок кандидатов модели не меняется. `probability` всегда `null`, `calibrated` —
`false`. `raw_slug` и `best_slug` — публичные строки общего ответа сцены; полный
внутренний отчёт не отдаётся.

## Ошибки

Тело ошибки: `{"error":"code","message":"описание"}`; при временной занятости
добавлены `retry_after` и заголовок `Retry-After`. Исключения распознавателя и пути
к файлам не передаются.

| Код | Значение | Действие |
|---|---|---|
| 401 | Нет или истёк токен (сервис) | Получить новый токен и повторить один раз |
| 413 | Файл больше лимита | Уменьшить фото |
| 415 / 422 | Неподдерживаемый формат, битый файл, неверная рамка | Исправить запрос |
| 429 | Превышена частота (сервис) | Ждать `Retry-After`, не перевыпускать токен в цикле |
| 502 / 503 | Распознаватель недоступен, не готов или очередь занята | Повторить позже |
| 504 | Распознавание не уложилось во время | Повторить или обрезать сцену рамкой |

## Пакет карточек шлюза

```text
web-assets/
  manifest.json
  cards.json
  thumbnails/<sha256>.jpg
```

Манифест `wine-scanner-web-assets-v1` содержит профиль распознавателя, происхождение
экспорта, число карточек и эталонов и `files`: относительное имя → SHA-256 и размер.
`cards.json` (`wine-scanner-cards-v1`) — карточки по slug и `reference_sha256`, если
эталон есть. Выпущенный пакет содержит 2136 карточек и 2094 миниатюры.

При запуске проверяются SHA манифеста из окружения, профиль и SHA каждого файла;
выход за каталог пакета запрещён. Изменённый пакет требует нового манифеста и
новых настроек.

Пакет карточек **не содержит весов** и сам не распознаёт. Для Linux-ядра нужен
отдельный пакет моделей, галереи, индекса и профилей — см. [CORE](CORE.md);
для Mac-варианта — подготовленная среда нативного распознавателя.
